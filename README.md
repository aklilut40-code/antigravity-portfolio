# Antigravity Portfolio

A modern, interactive personal portfolio website built to showcase a software engineer's work, free developer roadmaps, featured projects, and AI-powered assistance. The project combines a premium dark UI, smooth animations, downloadable PDF learning resources, and a contact form into a single polished landing page.

## Overview

Antigravity is a lightweight static web project designed to present a developer brand in a visually engaging way. It focuses on three main goals:

- Highlighting the portfolio owner's work and expertise
- Providing free educational roadmaps for aspiring developers
- Creating an approachable, AI-assisted user experience

The site is fully front-end based, making it easy to run locally, customize, and deploy to static hosting providers such as GitHub Pages or Netlify.

## Features

- Responsive portfolio layout for desktop and mobile devices
- Animated hero section with glowing visual styling
- Floating particle background and smooth scroll interactions
- Developer roadmap cards with downloadable PDF resources
- AI chat widget for quick portfolio queries
- Featured projects section
- Contact form section with user-friendly interaction design
- Modern typography, glassmorphism-inspired UI, and gradient accents

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Local PDF assets for educational resources

## Getting Started

Because this is a static site, there is no complex build process required.

### 1. Clone the repository

```bash
git clone https://github.com/aklilut40-code/antigravity-portfolio.git
cd antigravity-portfolio
```

### 2. Run locally

You can serve the project with any static file server. For example:

```bash
python -m http.server 8000
```

Then open the following in your browser:

```text
http://localhost:8000
```

## Customization

You can personalize the site by editing the following areas:

- `index.html` — page content, sections, links, and text
- `style.css` — colors, spacing, animations, and design system
- `script.js` — UI behavior, chat responses, and interactions
- `aklilu-profile.png` — profile image
- `pdfs/` — roadmap assets and downloadable resources
